# Home visual evidence

The isolated Home story composes the public shell, supplied portrait, editable copy/identity view models, and inline contact slot. Its sample copy comes from the Figma frames; production content initialization has its own review.

References: [desktop](https://www.figma.com/design/viiamFWKh3yqWHBfl1PJA3/Elspeth-Eastman-Redesign?node-id=244-425) and [mobile](https://www.figma.com/design/viiamFWKh3yqWHBfl1PJA3/Elspeth-Eastman-Redesign?node-id=8-204).

The [desktop capture](desktop.png) uses 1728 × 996 and the [mobile capture](mobile.png) uses 400 × 1262. Both were rendered in the pinned Playwright Chromium on macOS, compared with Figma, and checked for horizontal overflow and browser errors. Georgia and Arial resolve to the platform fonts; the supplied portrait and send icon retain their source files. [Browser checks](checks.json) also record mobile navigation dismissal and forward/reverse keyboard wrapping in the content dialog.

These captures demonstrate presentation. The final cutover review adds the real API/CMS browser flows and reproducible Linux visual baselines.
